# v2.2.0 — 经典玻璃 / 工作台双界面

## 上一版核查

v2.1.0 的 Pages 部署步骤成功，但发布后的浏览器验收在初始化阶段失败：mode badge 一直停留在静态 HTML 的“本机保存”，不能把上次任务称为完整验收通过。共享后端已发布；GitHub 首次归档也已成功。新版本增加可见的模块加载失败提示和网络诊断，继续执行部署前、部署后的真实浏览器验收。

对比 v1 与 v2.1，base.css、workspace.css、dialogs.css、responsive.css 保持逐字节相同；改变来自 team.css、机构页头、工具栏、默认数据视图和共享接入，并非整体重写了图片引擎。

## 展示与数据

- 默认使用“经典玻璃”：恢复原来的主标题、轻盈排版、卡片、色彩和叠放图片；完整机构名称以紧凑形式保留。
- 月亮旁的四角十字星切换至现有“工作台”界面，再次点击返回。选择只保存在本浏览器。
- 切换仅改变根节点 data-ui，不重新加载页面，不更换数据源，不重建记录或图片节点，不调用写入 API。活动、附件、草稿、筛选与当前图片索引共用同一份状态。
- 月亮仍只负责深浅色，与十字星独立。
- 正文和页脚只使用学校校徽。此前学院组合图片从页面移除；原始文件保留在历史中，不冒充独立院徽。
- scripts/prepare-emblem.py 从已核实的原图生成真正带 alpha 通道的透明底校徽，保留原比例，不重绘字形。构建时生成，不依赖外部热链。

## 示例保留

免登录共享、暂存、Excel 导入、附件原文件校验、回收站和 GitHub 归档不因 UI 切换改变。共享保存与 GitHub 定时归档仍分别确认，不宣称每次写入都立即进入 Git 历史。
