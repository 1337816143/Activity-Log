# v2.2.1 — 活动类型设置

统一活动类型，顺序固定为：招聘宣讲、线上宣传、经验分享、指导讲座、就业实践、专项活动、部门活动。

新增与编辑表单、筛选、草稿恢复、Excel 导入共用一个分类字典。新活动默认部门活动。Excel 表内已填的有效类型保留；未填时使用页面选定的缺省类型；导入预览可逐条调整。非七项分类提示人工选择，不自动猜测。

旧的“部门工作”“交流分享”分别兼容为“部门活动”“经验分享”。其他不确定的旧分类原值保留，编辑时须选择新类型，不静默覆盖历史事实。共享库中原六条虚构示例的分类另按示例内容更新，记录、图片及所有附件不删除、不重建。

两套 UI 的排版、样式、校徽、十字星开关、月亮开关、图片引擎、免登录共享和管理员删除保护均保留；只更新分类选项、对应色签、导入分类和版本号。验证包括七种类型真实保存/刷新/筛选、编辑、导入分类选择和旧有全部回归测试。自动化仅操作 qa 测试空间。

回归中修复两项实际问题：Excel 单元格对象先提取文本再匹配类型，防止有效类别变成空白；编辑器打开时同步设置焦点，去掉会在快速输入过程中抢回活动名称输入框的延迟焦点。保留原有全部断言，不通过降低验收标准绕过问题。
