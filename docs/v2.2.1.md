# v2.2.1 · 活动类型及自定义名称

预设按用户指定顺序：招聘宣讲、线上宣传、经验分享、指导讲座、就业实践、专项活动、部门活动；末项为其他。新增活动默认部门活动。

选择其他时展示自定义名称输入框，最多 50 个字符。非空名称直接写入现有 category 字段，留空保留其他。不会只保存“其他”而丢掉自定义内容。可从已存在的非预设名称中复用；保存后用于卡片、搜索、筛选和导出。

本机草稿及共享草稿保存完整分类选择和自定义输入，继续填写及跨浏览器恢复均保留。旧草稿与历史分类不属于七个预设时，以“其他＋原名称”恢复；仅编辑备注或工作不应改掉类别。

历史表格自动识别活动类型/活动类别/类型/类别/分类列；没提供类型则默认其他，不擅自推测。导入预览新增活动类型列，支持选择预设或填写名称。导入指纹仍按既有分工记录口径去重；更改分类不应偷偷重导已有记录，需要编辑现有记录。

复用现有 UI、共享 API、草稿库、删除保护和归档格式；不改示例或实际历史数据，不调整界面切换、图片、校徽。所有写入型自动化验收在 qa 隔离空间，绝不改 main 数据。
