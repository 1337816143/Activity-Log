# 中国农业大学土地科学与技术学院就业指导部活动记录系统

**v2.2.1 · 双界面、免登录共享版**

正式网址：https://1337816143.github.io/Activity-Log/

成员无需 GitHub 账号、授权、团队密钥或登录。所有访客可以查看、新增、编辑和上传。删除已保存活动、恢复活动、移除已保存附件必须经过服务端管理员密码验证。删除进入回收站，保留原附件及修改历史。密码明文和校验值不在前端或公开仓库中。

## 活动类型

统一按顺序提供：招聘宣讲、线上宣传、经验分享、指导讲座、就业实践、专项活动、部门活动。新增、编辑、筛选、草稿恢复与 Excel 导入共用 `assets/categories.js`。新记录默认部门活动；Excel 原表没有类型时可设置缺省类型，导入前也可逐条修正。表内明确有效类型会保留，未知类型提示人工选择，不凭活动名称猜测。

所有示例记录与原附件保留，仅更新分类标签。两套 UI、透明校徽、图片引擎及免登录共享不改动。

## 两套界面，同一份数据

默认是恢复原版视觉的“经典玻璃”；右上角月亮旁的四角十字星切换至保留的“工作台”，再次点击返回。月亮只负责深浅色，两个开关互相独立。

切换仅改变根节点的 `data-ui`，不刷新网页、不重新创建活动、不更换 API、草稿库或文件库，不重建图片动画节点。活动、附件、选中记录、搜索条件和图片索引保持不变。UI 偏好保存在当前浏览器，不强制改变其他成员的界面。v1 的基础、卡片、对话框和响应式样式仍被复用。

按使用者明确要求，原来六条虚构示例和十三份示例附件已一次性复制进团队资料库，备注中明确标为虚构。可以通过管理员密码删除；删除后不会在刷新、重新部署或切换 UI 时自动再生。“查看示例”仍提供独立的只读演示，不等于恢复已删除的团队记录。

## 数据边界

这是用户明确要求的**免登录公共协作**，不是成员身份隔离系统。拿到网址的人均可访问和修改；没有登录也就不能证明操作者真实身份。现有 GitHub 仓库为公开仓库，归档分支及全部历史同样公开。请勿上传身份证、私人联系方式清单、保密文件或其他敏感材料。管理员密码仅防止网页中的特定误删，不限制正常编辑，也不限制仓库拥有者直接操作 Git。

旧版 IndexedDB 资料不会自动公开上传。通过“共享与备份 → 检查并迁入旧记录”确认后才复制到团队库，原本机副本保留。

## 共享保存与 GitHub 归档

正式保存首先写入 Floot 托管 Postgres 数据库；其他成员刷新或切回窗口即可读取。页面不持续高频轮询。附件先直传临时私有对象，经服务端 SHA-256 校验后复制封存到支持跨域读取的公共 CDN。原上传链接无法覆盖封存文件。附件是公共共享资料，不应将它们视为私密内容。

GitHub Actions `backup.yml` 定时目标为约每 5 分钟一次，通过仓库 OIDC 短期身份访问归档接口，以运行器自带 GitHub 令牌提交 `team-data` 分支。**不是实时备份承诺**：调度、排队、网络、服务额度等可能延迟。页面分别显示共享版本、已归档版本和最后确认时间。成员端没有 GitHub 凭据；服务端也不需要长期 GitHub PAT。

归档包括正式记录、共享草稿、回收站、所有修改历史和附件原文件。`data/manifest.json` 是快照，`history/` 保留变更记录，`attachments/` 按 ID 存储原字节；清单记录原名、格式、大小和 SHA-256。`team-data` 不用于网站部署。归档没有管理员校验值、数据库凭据、IP 信息或临时签名链接。归档恢复需按历史最后修订重建，不能把它冒充旧版 `.activitylog` 导入文件。

GitHub 定时任务仅在默认分支运行；公开仓库长时间无仓库活动时，GitHub 可能停用计划任务。管理员应关注 Actions 失败与归档时间，必要时在仓库中重新启用。应用后台托管及用量受供应商计划限制，超额可能需要扩容或付费，不承诺无限永久免费。

## 自动暂存与 Excel 导入

停止输入约 0.6 秒后暂存本机草稿，原附件先暂存再生成缩略图。停止输入约 30 秒后尝试同步团队草稿，也可以手动“暂存本机”或“暂存到团队”。不完整字段可以暂存。刷新后从草稿箱继续；失败不显示云端成功。清除浏览器数据仍会丢失尚未上传的草稿，不要用无痕窗口保存重要记录。

XLSX、XLS、CSV 由本机 Web Worker 中的自托管 SheetJS 0.20.3 解析，不执行宏或公式。支持多工作表、重复/换序表头、显式合并单元格、连续分组、纵向字段表以及手动映射列与起始行。每一条保留“人员—具体工作”的对应关系。

`9.18` 等无年份日期必须确认年份；数值 `9.2` 可能丢失尾零，系统标记而不猜作 9 月 2 日或 20 日。导入前逐条可编辑、勾选、检查警告；用户确认后才上传。特殊布局可能需要手动映射或整理，不声称识别任意 Excel，图片和扫描表不会被伪装成已读取的 Excel。

单 Excel 文件 20 MB，最多 10000 行/200 列，单批确认最多 500 条；隐藏工作表默认不导入。导入指纹可跳过相同分工记录的重复导入。

## 附件、官方标识与容量

顶层图片完整显示，后续卡片叠放。支持滚轮、方向键、数字小键盘 8/2/4/6、拖动和触摸切换，以及原始像素查看、原文件下载。最多六层动画节点，支持减少动态效果；流畅程度仍受设备、图片大小及网络影响。

支持浏览器图片、PDF、音视频及安全纯文本预览；Word、Excel、PowerPoint、压缩包等保留原文件并提供下载，不做第三方在线转换。PDF 和媒体编码支持取决于浏览器。

单附件 50 MB，每条活动 100 个，一批添加 200 MB。共享存储目前设 2 GB 安全额度，包含历史和暂存附件。浏览器完整备份支持附件原始总量不超过 200 MB；CSV 仅含文字，不能替代完整附件备份。版本冲突会被拒绝，不会悄悄覆盖别人刚保存的修改。

页面只使用已核实的中国农业大学校徽，保留完整系统名称。此前的学院组合图已从界面移除，不冒充院徽。`assets/identity/sources.json` 记录官方来源。`scripts/prepare-emblem.py` 在构建时从原图去除白底，生成真正有 alpha 通道的透明 PNG；保持比例，不重绘字形。页头、侧栏和页脚一致使用该图。
