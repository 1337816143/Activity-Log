# 中国农业大学土地科学与技术学院就业指导部活动记录系统

**v2.1.0 · 免登录共享版**

正式网址：https://1337816143.github.io/Activity-Log/

成员不需要 GitHub 账号、授权、密钥或登录。所有访客可以查看、新增、编辑活动和上传附件。已保存活动的删除、恢复、移除已保存附件必须经过服务端管理员密码验证。删除只移入回收站，保留附件及修改历史。

## 必须知道的数据边界

这是用户明确要求的**免登录公共协作**，不是成员身份隔离系统。拿到网址的人均可以访问和修改资料。新增、修改保留历史便于追溯，但无登录无法证明操作者的真实身份。现有 GitHub 仓库是公开的，归档分支及其历史同样公开。请勿上传身份证、联系方式清单、私人材料或其他保密资料。网页管理员密码仅防止特定误删，不阻止正常编辑，也不能限制仓库拥有者直接操作 Git 历史。

旧版 IndexedDB 数据不会自动公开上传。通过“共享与备份 → 检查并迁入旧记录”明确确认后才迁入共享库；原本机副本保留。示例全部虚构，不进入团队资料库。

## 保存与 GitHub 归档是两步

正式保存首先写入 Floot 托管的 Postgres 共享数据库，附件由浏览器直传私有对象存储。写入成功后其他设备刷新或切回窗口即可看到，不需登录。页面不使用持续高频轮询。

GitHub Actions `backup.yml` 的定时目标为约每 5 分钟一次，运行时通过短期 OIDC 身份访问归档接口，以运行器自带 GitHub 令牌提交 `team-data` 分支。**它不是实时同步承诺**：GitHub 的排队、调度、故障或账号服务限制会延迟归档。页面显示共享版本、已归档版本及最后确认时间。网页不含个人 GitHub 令牌；后台也无需配置长期 GitHub PAT。

归档包含正式记录、共享草稿、回收站、全部修订及原附件字节。文件按 ID 安全命名，清单记录原名、类型、大小、SHA-256。归档恢复需按历史最后修订重建状态，不能将其伪装成旧版 `.activitylog` 浏览器备份。`team-data` 不用于部署站点。

## 草稿

停止输入约 0.6 秒后保存本机草稿；附件原字节先暂存，再生成缩略图。停止输入约 30 秒后尝试同步共享草稿，也可点“暂存本机”或“暂存到团队”。离线/失败不会冒称云端保存成功。刷新后可从草稿箱继续。清除浏览器存储仍会丢失尚未成功上传的草稿；不要使用无痕窗口保存重要资料。

## 历史 Excel

自托管 SheetJS 0.20.3，在 Web Worker 中解析 XLSX、XLS、CSV。支持多工作表、重复/换序表头、显式合并单元格、连续分组、纵向字段表、手动指定列及起始行。逐行保存人员与具体工作的对应关系，不将分工混合。

`9.18` 这类日期必须确认缺省年份。数字 `9.2` 可能丢失尾零，会标记并要求核对，不猜作 9 月 2 日或 20 日。导入前可以编辑、取消勾选和确认提示；确认后才上传。无法可靠识别的特殊布局需要手动映射或整理，不声称识别任意 Excel。截图或扫描图片不会冒充 Excel 数据读取。

单次文件最大 20 MB、识别最多 10000 行/200 列、每批确认导入最多 500 条。隐藏工作表默认不导入；不执行公式或宏。导入指纹可防止同批资料被反复导入。

## 附件与交互

顶层图片完整显示，后续卡片叠放。鼠标滚轮、方向键、数字小键盘 8/2/4/6、拖动/触摸切换，支持大图、原始像素及原文件下载。单附件 50 MB，每条活动最多 100 个，一批最多 200 MB，共享存储当前设 2 GB 安全额度（含历史与暂存、测试附件）。备份导出在浏览器中的原始附件总量限制为 200 MB。

支持浏览器图片/PDF/音视频和安全文本预览；Word、Excel、PowerPoint 等先保存原文件，可下载使用本机软件，暂不内嵌解析。不能保证所有浏览器支持所有媒体编码。

文件先传至临时对象，服务端验证完整性后封存至新随机对象。浏览器持有的临时上传链接不能覆盖已保存的正式附件。失败可重试。并发修订采用版本检查，拒绝悄悄覆盖他人已保存的修改。

## 标识来源

`assets/identity/sources.json` 记录官方素材来源；图片按原比例展示，不改写校名或重绘徽标。中国农大校徽已核实。学院官网提供的是校徽与学院文字的官方组合标识，不是另外独立核实的院徽。
